# ADR 0004: independent public demo and private originals

Status: accepted.

The original dataset and teaching materials have no supplied redistribution license. Preserve them locally, ignore them in Git and document a manual authorized-data import. Supply a separate independently generated synthetic demo with explicit labels and deterministic normal/warning/critical scenarios.

The default experience can be reproduced without a cloud account or language model. All analytics still run through the actual backend/graph/database; only the commercial observations are synthetic.

Trade-off: a public checkout does not include the original history. Original-data validation evidence is documented, and no license is assigned to third-party material before a rights review.
