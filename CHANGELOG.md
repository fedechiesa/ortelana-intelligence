# Changelog

## 1.0.0 — 2026-11-24

First portfolio release of the independently implemented Ortelana Intelligence application.

- Connected React workspace for analytics, execution evidence, supervisor review, decisions and monitoring.
- Deterministic LangGraph fan-out/join with PostgreSQL checkpoints, critical interrupts and authenticated decision/resume.
- Versioned policies, immutable evidence, append-only audit/decisions, idempotency and concurrency/restart protections.
- Independently generated synthetic demo, reporting-year semantics and explicit missing/cohort coverage handling.
- Inactive n8n manual/weekly workflows, bounded retries, Prometheus and two provisioned Grafana dashboards.
- Digest-pinned six-service Compose stack, restricted database roles, reproducible checks and actual screenshots.
- Publication audit, sanitized development history and professional technical/operational documentation. Original datasets and copied teaching material are excluded.

No LLM, predictive model or real commercial action is included. Project-wide licensing remains pending the rights review in `THIRD_PARTY_NOTICES.md`.
